# Designer 3 Implementation Plan (designer plugin)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A third designer flow, `designer3`, that shows a complete door after the visitor picks a type and a style. It marks every changeable part on the door, nudges the visitor to save, then offers side and top lights and pushes for a quote. Behind it: a call-back request kind, a data export, and an experiment snapshot for the manager app.

**Architecture:**
- A new flow in `assets/js/designer3/`, built from small UMD modules:
  - pure logic: defaults, frame mapping, hotspots, nudge
  - DOM views: screens, toolbox, saved and frame screens, call back
  - an app controller
- It reuses `HD_DD_Wizard` for design state, `HD_DD_Preview`/`HD_DD_RenderModel` for drawing, and the existing `/save` routes.
- Server side:
  - a `callback` kind and route
  - a `callback_at` column on the experiment visitors table
  - `HD_DD_Experiments::snapshot()` and `export_data()`
  - a wp-admin JSON download
- Top-light artwork is captured from Endurance and drawn only when the caller opts in, so Classic's pictures cannot change.

**Tech Stack:** WordPress plugin PHP (plain-PHP tests with stubs), vanilla ES5 JavaScript (UMD, plain-Node tests), CSS.

**Spec:** `docs/superpowers/specs/2026-10-21-designer-3-design.md`. Read it first. The manager-app side (scoreboard, paths, analytics push) is a separate plan: `../manager-app/docs/superpowers/plans/2026-10-21-designer-3-scoreboard.md`.

- **Names**
  - Flow key `designer3`, label `Designer 3`.
  - Funnel `door-designer-v4`.
  - Enquiry kind `callback`. Hook `hd_dd_callback_requested($payload, $id)`.
  - Route `POST /save/{token}/callback`.
- **`ORDER_V4`, in this exact order:** `opened:0, type:1, style:2, shown:3, colour:4, handle:5, letterplate:6, knocker:7, more:8, saved:9, frame:10, quoteform:11, callback:12`. The lead is the existing `funnel.lead()`, not a step. All keys are lower-case.
- **No spy hole** anywhere: no toolbox row, no dot, no step.
- **Toolbox rows, in this order:** Colour, Door style, Handle, Letterplate, Knocker, More options. More options holds hinge side, inside colour, door glass, hardware finish and letterplate position.
- **Nudge:** after the visitor's **3rd** change, once per visit (sessionStorage key `hd_dd_d3_nudged`), dismissible.
- **Frame step**
  - Only for types whose `Frame Design` offers more than `No Sidelights`. Double Door skips it.

- **Call back**
  - A lead for the business, **not** an A/B conversion. It must not fire `hd_dd_enquiry_submitted`, must not set `converted_at`, and must not call `funnel.lead()`.
- **Copy**
  - Guide price comes from `CFG.trust.guidePrice`; the trust block is `HD_DD_Trust.renderProof`.
  - Save note: "Just your email. We'll send you a link to it."
- **Verification**
  - JS: `node tests/js/<name>.test.js`. Run all with `for f in tests/js/*.test.js; do node "$f" || echo FAIL $f; done`.
  - PHP: `php tests/php/run.php`.

## Review Focus

1. **A style with no knocker or no bottom letterplate position.** The defaults must never pick a knocker or position the style lacks. Covered by Task 5 tests on a style missing from `knockerByStyle` and one with `letterplatePosStyles[style]==='bottom'`.
2. **Changing door style after customising.** Choices still valid for the new style are kept; invalid ones fall back to that style's defaults, and the dots move with the new geometry. Task 9 test `restyle keeps valid furniture`.
3. **A saved link opened in a browser that is in the Classic arm.** It reopens Designer 3, on the saved screen. Task 1 test on `storedFlow` and Task 10 test on `loadSaved`.
4. **A call back on a design that already became an enquiry, or the reverse.** The route returns 409; neither row is double-counted. Task 3 tests.
5. **A Toplight design drawn by Classic.** It must render exactly as today (a plain door). Task 7 test `classic assemble ignores toplights`.
